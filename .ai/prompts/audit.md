# Шаблон промпта: Аудит кода

Используй этот шаблон для полного аудита репозитория.

---

## Промпт для полного аудита

```
Прочитай AGENTS.md, .ai/project.md, .ai/architecture.md, .ai/decisions.md, .ai/tasks.md.

Выполни полный аудит репозитория PDFX. НЕ вноси изменений, только анализируй и докладывай.

**Проверь следующее:**

1. TypeScript
   - Запусти npx tsc --noEmit
   - Перечисли все ошибки

2. Дублирование кода
   - Есть ли дублированные slug в tools.ts?
   - Есть ли дублированные экспорты в pdf-utils.ts?
   - Есть ли дублированные переводы в tool-translations.ts?

3. Соответствие инструментов
   - Все ли slug из tools.ts имеют case в handleProcess() в tool-page.tsx?
   - Все ли slug имеют EN и RU переводы?

4. Размер файлов и техдолг
   - Сравни с .ai/tasks.md (секция "Технический долг")
   - Есть ли новые проблемы?

5. Зависимости
   - Есть ли неиспользуемые npm-пакеты?
   - Есть ли устаревшие?

6. Безопасность
   - Нет ли мест где пользовательский ввод используется небезопасно?
   - Нет ли XSS-уязвимостей в PDF-рендере?

**Формат ответа:**
- Критические проблемы (блокируют работу)
- Важные проблемы (нужно исправить)
- Незначительные проблемы
- Рекомендации

После аудита предложи обновить .ai/tasks.md с новыми найденными проблемами.
```

## Промпт для аудита конкретного инструмента

```
Прочитай AGENTS.md и .ai/architecture.md.

Проверь инструмент [slug] в PDFX:

1. Корректно ли работает функция в pdf-utils.ts?
2. Правильно ли обрабатываются edge cases (пустой PDF, 1 страница, большой файл)?
3. Соответствует ли UI паттернам остальных инструментов?
4. Есть ли EN и RU переводы?
5. Правильно ли работает download handler?

Протестируй через Playwright если возможно: http://localhost:5000/tools/[slug]
```

## Промпт для аудита производительности

```
Прочитай AGENTS.md и .ai/architecture.md (секция "Технический долг" → TD-01).

Проанализируй производительность PDFX:

1. Какие операции в pdf-utils.ts наиболее тяжёлые?
2. Где блокируется main thread?
3. Какие операции можно вынести в Web Worker?
4. Есть ли unnecessary re-renders в React?

НЕ вноси изменений. Только анализ с конкретными рекомендациями.
```
