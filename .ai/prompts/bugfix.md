# Шаблон промпта: Bug Fix

Используй этот шаблон когда просишь AI-агента исправить баг.

---

## Промпт для исправления бага

```
Прочитай AGENTS.md и .ai/architecture.md.

Исправь баг в репозитории PDFX:

**Описание бага:**
[Что происходит неправильно]

**Шаги воспроизведения:**
1. [шаг 1]
2. [шаг 2]
3. [шаг 3]

**Ожидаемое поведение:**
[Что должно происходить]

**Фактическое поведение:**
[Что происходит сейчас]

**Предположение о причине:**
[опционально — где может быть проблема]

**Требования к исправлению:**
- НЕ рефакторить окружающий код
- НЕ менять поведение других инструментов
- Запустить npx tsc --noEmit → 0 ошибок
- Если исправление значимое — обновить .ai/changelog.md
```

---

## Быстрый промпт (для очевидных багов)

```
Прочитай AGENTS.md.

В PDFX инструмент [slug] делает [неправильное поведение].
Должно быть: [правильное поведение].
Исправь. 0 TypeScript ошибок. Ничего не рефакторить.
```

---

## Промпт для TypeScript ошибок

```
Прочитай AGENTS.md.

В PDFX есть TypeScript ошибки. Запусти npx tsc --noEmit и исправь ВСЕ ошибки.

Правила:
- Исправлять только типы, не логику
- Не рефакторить код
- Не менять поведение
- Результат: npx tsc --noEmit → 0 ошибок
```
