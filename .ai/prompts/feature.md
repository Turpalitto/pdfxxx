# Шаблон промпта: Новая функция / New Feature

Используй этот шаблон когда просишь AI-агента добавить новый инструмент или функцию.

---

## Промпт для нового PDF-инструмента

```
Прочитай AGENTS.md и .ai/project.md, .ai/architecture.md, .ai/decisions.md.

Добавь новый PDF-инструмент в репозиторий PDFX:

**Slug:** [название-инструмента]
**Категория:** [organize | convert-from | convert-to | security | utility | ocr | optimize]
**Цвет:** [blue|violet|green|orange|teal|indigo|amber|rose|sky|slate]
**Что делает:** [описание на 1-2 предложения]
**Входной файл:** [.pdf | .pdf,.docx | ...]
**Выходной файл:** [pdf | zip | txt | docx | xlsx | html]

**Ожидаемое поведение:**
1. Пользователь загружает PDF
2. [опциональные настройки]
3. Нажимает кнопку обработки
4. Скачивает результат

**Требования:**
- Всё должно работать в браузере без backend
- Использовать только уже установленные npm пакеты (pdf-lib, pdfjs-dist, jszip, fabric, tesseract.js)
- Следовать чеклисту из AGENTS.md
- После добавления запустить npx tsc --noEmit и убедиться в 0 ошибок
- Обновить .ai/changelog.md и .ai/tasks.md
```

## Промпт для улучшения существующего инструмента

```
Прочитай AGENTS.md и .ai/architecture.md.

Улучши существующий инструмент [slug] в PDFX:

**Текущее поведение:** [описание]
**Желаемое поведение:** [описание]
**Файлы которые нужно изменить:** tool-page.tsx, pdf-utils.ts (при необходимости)

Не менять архитектуру. Не трогать цветовую палитру. 0 TypeScript ошибок.
```

**Название:** [имя компонента]
