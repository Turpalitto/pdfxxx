ЧТО ИСПРАВИТЬ / ДОБАВИТЬ

1. Исправить кроссплатформенный запуск
- добавить `cross-env`
- заменить scripts:
  "dev": "cross-env NODE_ENV=development tsx server/index.ts"
  "start": "cross-env NODE_ENV=production node dist/index.cjs"

2. Исправить запуск сервера на Windows
- убрать `reusePort: true`
- либо включать его только не на win32

3. Убрать ложную “redaction”
- не рисовать прямоугольник поверх текста как будто это безопасная редактура
- либо временно скрыть/отключить `redact-pdf`
- либо внедрить реальное удаление/затирание контента, после которого текст больше не извлекается

4. Починить/убрать `protectPdf`
- текущая реализация на `pdf-lib` не работает
- либо заменить библиотеку на ту, которая реально поддерживает encryption
- либо временно убрать tool из UI, пока нет рабочей реализации

5. Пересобрать `compressPdf`
- сейчас это не “3 уровня сжатия”
- либо реализовать реальную оптимизацию ресурсов/изображений
- либо переименовать инструмент в “rewrite/optimize structure”
- обязательно добавить проверку, что размер не растёт без предупреждения

6. Синхронизировать accept и реальные форматы
- убрать `.doc` из accept, если поддерживается только `.docx`
- убрать `.webp` из accept, если конвертер реально работает только с JPG/PNG
- либо добавить полноценную конвертацию `.doc` и `.webp`

7. Синхронизировать описания и UI
- `reorder-pages`: либо сделать drag-and-drop, либо переписать description
- `sign-pdf`: либо дать рисование/загрузку изображения, либо переписать description
- `delete-pages`: либо визуальный selector, либо переписать description
- проверить остальные tool descriptions на такие же расхождения

8. Добавить тесты
- unit test на `protectPdf` с проверкой, что функция реально создаёт password-protected PDF
- regression test на `redactPdf`, который проверяет, что исходный текст больше не извлекается
- test на `compressPdf`, который проверяет ожидаемое уменьшение/неувеличение размера
- format acceptance test для `.doc/.docx/.webp/.png/.jpg`
- smoke test запуска на Windows

9. Обновить зависимости
- прогнать безопасное обновление по `npm audit`
- отдельно поднять версии, связанные с `rollup`, `minimatch`, `lodash`, `qs`
