Создай новый инструмент "Редактировать PDF" (Edit PDF) — аннотационный редактор, который работает полностью в браузере. Пользователь загружает PDF, редактирует его (добавляет текст, картинки, рисует, ставит подпись), и скачивает результат. Файл никогда не отправляется на сервер.
Технический стек:

pdfjs-dist — рендеринг страниц PDF в canvas
fabric.js (fabric) — интерактивный overlay-canvas для редактирования
pdf-lib — запись аннотаций обратно в PDF при сохранении

Архитектура (3 слоя):

PDF Layer: pdfjs-dist рендерит каждую страницу в <canvas> (read-only, только отображение)
Edit Layer: fabric.js canvas точно поверх каждой страницы — сюда добавляются все аннотации
Save Layer: при сохранении pdf-lib открывает оригинальный PDF и "впечатывает" все объекты из fabric.js canvas обратно в PDF

Функции редактора (тулбар слева или сверху):

Текст — клик на страницу → появляется текстовое поле. Настройки: шрифт (Arial, Times New Roman, Courier), размер (8-72pt), цвет, bold/italic
Изображение — загрузка картинки (PNG/JPG) → перетаскивание и масштабирование на странице
Рисование — свободное рисование кистью. Настройки: цвет, толщина линии (1-10px)
Подпись — модальное окно где пользователь рисует подпись → подпись добавляется как объект на страницу
Фигуры — прямоугольник, круг, линия, стрелка. Настройки: цвет заливки, цвет обводки, толщина
Маркер — полупрозрачный прямоугольник (opacity 0.3) жёлтого цвета для выделения текста
Ластик — клик на любой добавленный объект → удалить его
Undo/Redo — Ctrl+Z / Ctrl+Shift+Z

Навигация по страницам:

Превью всех страниц слева (миниатюры)
Клик на миниатюру → переход к странице
Текущая страница подсвечена
Скролл между страницами

Сохранение:

Кнопка "Скачать PDF"
При нажатии: пройти по всем страницам, собрать все объекты с fabric.js canvas
Для каждого объекта: определить его тип и координаты

Текст → pdf-lib drawText() с теми же координатами, шрифтом и размером
Изображение → pdf-lib drawImage()
Рисование/фигуры → конвертировать fabric canvas в PNG → pdf-lib drawImage() как overlay

UI/UX требования:

Тёмная тема, совпадающая с остальным сайтом PDFX
Тулбар: иконки с подсказками (tooltip)
Активный инструмент подсвечен фиолетовым (accent color)
Drag & drop зона для загрузки PDF
Прогресс-бар при загрузке больших PDF
Адаптивный дизайн (но основной фокус на десктоп)
Zoom: кнопки +/- и fit-to-width

Важно:

Всё работает в браузере, БЕЗ серверных запросов
Координаты fabric.js нужно корректно пересчитать в координаты pdf-lib (в PDF ось Y идёт снизу вверх, в canvas — сверху вниз)
При конвертации координат учитывать масштаб отображения (viewport scale)
Максимальный размер файла: 25MB (для бесплатных), показывать ошибку если больше
Добавить страницу инструмента по URL /tools/edit-pdf
Язык интерфейса: русский (с поддержкой i18n как в остальных инструментах)
На странице инструмента справа показать блок "Как использовать" (как у других инструментов)
Добавить в раздел "Похожие инструменты": Подписать PDF, Водяной знак, Защитить PDF
